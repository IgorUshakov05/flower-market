# FlowerShop

## Описание проекта

**FlowerShop** — это современный интернет-магазин цветов, созданный с использованием фреймворка Next.js. Здесь вы найдете широкий выбор свежих цветов, готовых букетов и композиций для любых случаев жизни. Проект разработан с акцентом на производительность, удобство использования и гибкость масштабирования.

---

## Стек технологий

- **Next.js**: Фреймворк для серверного рендеринга и статической генерации.
- **TypeScript**: Статическая типизация для надежности кода.
- **ESLint**: Инструмент для анализа кода и поддержания единого стиля.
- **Tailwind CSS**: Утилитарный фреймворк для быстрой верстки.
- **Turbopack**: Экспериментальный инструмент для ускорения сборки проекта.
- **App Router**: Новый роутер Next.js для модульной архитектуры приложения.
- **Custom Import Alias (`@/*`)**: Удобная система импорта файлов.
